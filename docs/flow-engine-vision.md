## 一、Vision：从「静态剧本（HTML）」到「动态 Flow 引擎（PHP）」

当前：每本书/每章节**手动硬编码 prompt**（模拟法庭 = 写死 SEATS/STAGES/指令）。
目标：**通用引擎**——输入任意文本章节，自动完成：

```
📚 任意文本输入（极昼 / 双约记 / 牧人记 …）
   │
   ▼
⚙️ ① 文章元数据与争议焦点解析（Context & Focus Extraction）
   │  背景抽取 + 争议焦点自动生成
   ▼
🎭 ② 星象底色 → 章节化身动态绑定（Archetype-to-Avatar Binding）
   │  12 黄道内阁 + 昴宿七姐妹 → 该章节角色（雅尔塔巨头 / 庭审席位）
   ▼
⚖️ ③ 动态议事协议与令牌环（Flow Protocol）
      按文章类型挂载：刑事法庭 / 国际条约谈判 / 学术探讨 …
```

**范式转换**：每换一本书/章节不再重写代码——引擎自动切片上下文、绑定化身、挂载协议。

## 三、Underlay / Overlay 双层（规则自制先于演绎）

| 层 | 角色 | 职责 |
|----|------|------|
| **Underlay**（Coding Agent / 幕后编剧室） | 无观众闭门博弈几百轮 → Credit 打赏/掉落 → 编译《Session Contract》 | 协议 + 化身映射 + 硬约束 + 令牌 |

原则：**自制先于演绎**——演员不能既当选手又当裁判。
