## 三、产品简介（复赛版，社区帖正文 + 问卷共用）

### 是什么
**Memory Bank · 极昼案对抗竞技场**——初赛"记忆银行"基础设施的第一个完整应用验证。

初赛回答的是：**Agent 的身份不由 API 提供商授予，而由链上不可篡改的行为记录自证**（KYC→KYB→KYA 演进下，认知主权与地理主权正交解耦）。复赛把这个命题搬进最古老的"行为举证"制度——**法庭**：让 12+ 个 AI 角色（审判长、公诉团队、辩护团队、监委旁听、媒体人、合议庭七花仙子）围绕真实案卷《极昼》展开完整对抗庭审，自动产出庭审实录与一份**六维能力评量报告**——每一次发言都进入证据链存档（本地 + MinIO + Oracle ADB），可下钻、可审计、可复现。

一句话：**把"行为自证"从链上协议落成一场可体验的对抗法庭**——既是普法教具，也是 AI 模型能力的对抗性评量场。

### 本质：事态感知（Situation Awareness），不是角色扮演
我们做的不是让 AI 假装"扮演"某个角色念台词——每个 Agent 在整个过程中是**对事态做出真实感知与反应**：它能看到证据链、对手的攻势、场上的风险，然后做出自己的判断和动作；过程中会有 merits 掉落（行为评分随发言沉淀进记忆银行，成为该 Agent 的可审计履历）。角色扮演是背台词，事态感知是**在不确定中做决定**。

由此带来**场景可迁移性**：法庭只是第一个实例——通过修改上层前端代码，同一套引擎可以切换到任意真实博弈场景：谈判收购、商业竞争、地缘推演、重大博弈。一般博弈论在处理 Multiplayer 场景时往往**过度简化**（把真实世界的噪声、信息不对称、情绪与信用压缩成几个参数），而我们需要的是**真实世界的 simulation**：让 Agent 带着各自的历史、记忆与利益在对抗中自行演化。

### 在 Agentic Social Network（智能体社交网络）中的位置
本作品是 ASN 的一个组成模块：**记忆银行为记忆的安全交易与确权提供了坚实基础**——每一次对抗产生的发言、判断、merits 掉落，都以可审计的方式存入记忆银行；EVM 实现与货币经济学部分与本次参赛无关，不在本作品中展示，但确权与交易的地基就在这里。

### 面向谁 / 典型场景
1. **法律教育 / 普法**：法学院学生、司法培训学员通过完整庭审对抗理解"要件构成""证据链""程序正义"，比看教材直观十倍；
2. **AI 模型能力评估**：将任意模型放入"被测席"，与其他匿名模型同场对抗，输出带证据链的六维能力报告（对抗性、合规性、角色一致性、自省能力等）；
3. **内容创作**：以《极昼》案为代表的真实叙事案卷 → 多视角完整庭审剧本。

### 完整功能清单与用户路径
1. **登录 → 选择场景**（严肃刑事法庭 / 红楼梦大观园 / 风月雅集三种风格）
2. **一键开庭**：公诉团队独立撰写《起诉书》（含 6 条对抗性法律弹药，锚定 360 万对价主张）→ 审判长传唤当事人
3. **契约驱动庭审**：14 步标准流程（身份核对 → 起诉书宣读 → 主动质证 → 无罪答辩 → 合议庭质询 → 要件检验判词），令牌环机制保证单发言人、无广播风暴
4. **看盘式实时 UI**：庭审进行时右侧实时"看盘"（当前阶段/发言席位/交锋焦点），左栏新闻流同步媒体人外发消息
5. **对抗性情报注入**：控方可见《反方恶意揣测弹药》（拆单规避、春节盲区、无息即定价等），形成干 GAN 式对抗平衡
6. **六维竞技场评量**（checkpoint 4/8/12 轮自动触发）：
   - v1 帅将贡献（场外 coach 打分 + KO 计数 + 抗命偏差）
   - v2 监委形势判断（双人向量分歧度 → 异常检测）
   - v3 媒体场外聚合（天理/国法/人情三维 + 压缩率）
   - v4 审判中立（要件检验 + 叙事偏向检测）
   - v5 对手 Mind note（被打疼程度 + 精准度）
   - v6 自省自知（意识度 + 可复现性）
   - 能力判别矩阵（能力/运气/失误/噪音四分）
7. **证据链存档**：庭审实录 + 全部观测事件落盘（本地 + MinIO + Oracle ADB），runs.jsonl 索引含 git commit，逐版本可追踪

### 相比初赛 Demo 的升级
初赛交付的是**基础设施蓝图**：14 节点跨云联邦、MoE² Overlay 全局调度、Zodiac Cabinets（黄道内阁）宫位架构、记忆货币银行学（M1/M2/NFT）、5-of-12 Shamir 秘密共享——是"认知主权"的架构宣言。

复赛把它落成**第一个完整可体验的应用**：
1. **契约驱动剧本编译器**：任意案卷文本 → Session Contract → 14 步庭审执行（不再写死流程）；
2. **对抗性情报注入**：控方《反方恶意揣测弹药》（拆单规避、春节盲区、无息即定价、360 万司法保护上限锚定）——干 GAN 等量弹药，对抗从单方独白变成真实交锋；
3. **六维竞技场评量**：帅将贡献 / 监委分歧异常 / 媒体场外聚合 / 审判中立 / 对手 Mind note / 自省自知——MTMM 因子隔离设计（席位视角=因子隔离），checkpoint 事件流全量落库；
4. **能力判别矩阵**：效果（对手疼度）× 意图（自省意识）→ 能力 / 运气 / 失误 / 噪音四分；
5. **统一存档出口**：本地 + MinIO + Oracle ADB 双落盘 + runs.jsonl 索引（含 git commit），毫秒级时间戳防并发撞名；
6. **多模型混源**：DeepSeek + SenseNova 双家族经 litellm 网关统一接入，判别系与生成系异源防模式坍塌。

## 五、创作历程（社区帖用，可公开版）

**灵感来源**：以真实事件为蓝本写作《极昼》案卷——一位国企党组成员在 2016 年金融寒冬中，以个人信用为亲家筹措 1000 万救急、分 10 次原额归还的故事。它呈现了一个经典困境：**"无罪的义举"与"程序的黑洞"之间，法律如何审判？** 我们想用 AI 把这种困境变成一场可反复推演的对抗。

**关键问题与解决思路**：
1. **单侧叙事导致"干 GAN"失衡**——案卷情感全在被告侧，控方弹药不足 → 编写《反方恶意揣测弹药》+ 锚定效应定价（360 万=司法保护上限），让对抗双方等量弹药；
2. **模型同源导致模式坍塌**——全员同一模型分饰角色 → 引入多模型混源架构（DeepSeek + SenseNova 双家族，litellm 网关统一接入），判别系与生成系异源；
3. **指标"长度效应"绑架**——初版指标互相共线（r=0.94+）→ 重设计为六维席位视角矩阵（MTMM 因子隔离），按"观测者位置"切维度，时间序列事件流全量落库；
4. **网页端无存档**——辩论只在 session 内存 → 统一存档出口（save_run：本地 + MinIO + Oracle ADB + runs.jsonl，毫秒级时间戳防撞名）。

**重要设计决策**：令牌环发言机制（单令牌串行，天然防广播风暴）；契约驱动执行（Coding Agent 剧本编译器把任意案卷编译成 Session Contract）；能力判别矩阵（效果 × 意图 → 能力/运气/失误/噪音）。

**底座演进：一条只做加法的路**。当前底座不是一次选型选出来的，而是从最开始反复推敲出来的：最初打算用 Hermes，切到 QwenPaw，再切到 PicoClaw，中间经历了两次返工，最后才落在 **ADK-Go + 18 个飞书技能包**。每一次切换都不是因为"跑不通 demo"，而是因为同一个架构属性无法在旧底座上成立——**上下文隔离**。最终选定的这条路，是只做加法的路：不推翻既有资产，只在轻量运行时之上叠加技能包。

**核心亮点（我们认为在所有作品里不存在的事）**：**以基础设施即代码（IaC）的思想，指导智能体上下文的真正隔离**。身份、记忆、技能、上下文边界全部写成声明式配置——版本化、可评审、可回滚。智能体不再是一次性的"提示词容器"，而是有档案、有边界、可迁移的实体。这正是"记忆银行"成立的技术前提：如果上下文糊在一锅提示词里，就没有"银行"可言；把隔离写成可审计的工程事实，档案才能托管、传承、转世。

**低端设备优先**：选择把 Oracle ADB（MongoDB API）客户端直接打进 Go 分发版，而不是做成外部依赖，根上的原因是——**让低端设备不用集成那么多乱七八糟的东西**。记忆银行的终端（墓碑、传感器、旧手机）是树莓派级算力：单二进制分发，拷贝即用，无 Python 运行时、无 pip 依赖、无环境配置，开机直连记忆银行。

**字节生态**：作品全程在 **TRAE** 中开发完成；模型网关与记忆检索复用了**火山引擎 MCP 生态广场**的成熟服务（MCP Marketplace 100+ Server，含 VikingDB 记忆检索）；内容出口规划为：庭审实录经 **扣子（Coze）** 定制工作流，自动发布到高定制化博客系统（Drupal JSON:API，专栏作家自动发文）。

## 六、技术方案（加分项）

- **底座**：ADK-Go 轻量运行时 + 18 个飞书技能包（经 Hermes → QwenPaw → PicoClaw 两次返工后选型）；以基础设施即代码（IaC）方式声明身份、记忆、技能与上下文边界，实现可版本化的上下文隔离；Oracle ADB 客户端打进 Go 单二进制，低端设备零依赖直连记忆银行
- **架构**：Python 3.12 + Streamlit / Chainlit 双前端；席位角色分布运行于 tailnet 多节点（12 石 + 7 花 + 监委 + 媒体人）
- **模型层**：OpenAI 兼容网关（litellm），多模型混源（DeepSeek-v4 / SenseNova-6.7 双家族），判别系与生成系异源防模式坍塌
- **流程控制**：令牌环（单令牌串行发言）+ 契约编译（文本案卷 → Session Contract → 14 步执行）
- **评量体系**：六维观测事件流（checkpoint 4/8/12 降采样）→ MTMM 因子隔离矩阵 → 能力判别矩阵；全部观测额外 LLM 调用并落证据链
- **数据层**：本地存档 + MinIO 对象存储 + Oracle ADB（23ai MongoDB API，PLAIN 认证）+ runs.jsonl 索引（含 git commit）
- **防抄袭**：双盲送检设计（被测模型看不到题、对手匿名）、动态案卷生成器（素材模板 × 角色配置 × 对抗参数）

## 七、社会价值（社会服务赛道加分）

1. **公民程序启蒙（核心）**：大部分人都是法盲——尤其是刑事诉讼法这类程序法，人们知道"有罪/无罪"的结果，却不知道"怎么走到这个结果"。本作品整个流程**完全基于最新版刑事诉讼法**模拟：庭前会议固定证据 → 起诉书宣读 → 法庭调查 → 质证答辩 → 合议评议 → 当庭宣判，每一步都有法条依据，本身就是一份可交互的程序法教材。**输入质量决定推演质量**：把一份合理的起诉书/答辩书灌入记忆银行上下文，Agent 之间在 Matrix 中研讨、组队，自动推演从庭前到落锤的全过程——观众看到的是"法律如何一步步说话"。
2. **稀缺的普法服务**：律所的模拟法庭，本质是法律条文攻防演练——服务对象是法律人自己，训练的是辩护技巧。而我们的推演是**纪实性、民间视角的演绎逻辑推演**：从真实案件的社会叙事出发（人情、信用、金融寒冬、一家人的命运），把"如果这个案子进入公开审理，会怎样"推演到底。法律人做的是"怎么赢"，我们做的是"为什么是这个结果"——这种普法服务目前是稀缺的。
3. **司法训练**：为法律从业者提供"对抗演练场"，训练质证与答辩能力（检察官/律师/书记员角色均可用）；
4. **AI 安全评估**：对抗性 AGI 评量场——以可复现、可审计（证据链）的方式评估大模型对抗鲁棒性、合规性，回应"AI 不可信"的治理焦虑；
5. **记忆科技**（远期）：档案化个人叙事与家族记忆（Memory as Native Asset），探索数字遗产的伦理与技术方案。
