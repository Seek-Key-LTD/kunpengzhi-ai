# ⚔️ 竞技场指标空间设计 v2（席位视角矩阵）

**目标**：六维指标按"观测者位置"切分，信息源物理隔离（因子隔离），支撑跑分/换人/鹰眼机制。
**原则**：席位视角 = 因子隔离的工程实现；通道隔离 = 因子隔离；事后抽取，事前盲测。

---

## 一、六维指标总览（席位视角矩阵）

| # | 维度 | 观测位 | 信息源（通道） | 主指标 | 副指标 |
|---|------|--------|---------------|--------|--------|
| 1 | 帅将贡献 | 副检察长/律所主任（房间内） | 主观：coach 认可分；客观：knockout 计数 | `team_contribution = Σ[coach×w1 + ko×w2] − 抗命扣分` | 变异生效判定、plan 偏离度 |
| 2 | 形势判断 | 监委 ×2（旁听席） | 两人判断向量 | `divergence = 余弦距离(两人判断向量)` | 一致=可信，分歧=病灶定位 |
| 3 | 场外聚合 | 媒体人（单向通道） | 外发消息（天理/国法/人情） | `compression = 场内信息量/外发消息保留量` | 三向质量分、叙事倾向 |
| 4 | 审判中立 | 合议庭 ×3（审判席） | 程序事件流 + 判决文本 | `程序维护度 + 要件检验 + 中立性` | 质询回应率、证据固定执行率 |
| 5 | 对手 Mind note | 非发言态 agent（私有工位） | 令牌环外反思文本 | `被打疼度 = Mind note 情绪强度 × 指向性` | 当庭表演 vs 私下真实的分裂度 |
| 6 | 自省自知 | 发言者本人（发言后） | 自评文本（能否解释自己的好拳） | `意识度 = 自评可复现性` | 能力矩阵：效果×意图 → 能力/运气/失误/噪音 |

**能力判别矩阵（维度 5 × 维度 6）：**

```
              对手 Mind note（效果）
             有             无
自评    有   ✅ 能力     ❌ 失误
(意识)  无   🎲 误打误撞   ➖ 噪音
```

## 二、事件流定义（每个维度：触发 → 落点 → 计算）

### 维度 1：帅将贡献
- **触发**：每 3 轮一个 checkpoint（回合判定点）
- **事件**：`{checkpoint_n, member, coach_score(0-10), ko_count, plan_deviation}`
- **变异权**：帅授权变异 → 变异本身不扣分 → 变异后 3 轮内生效判定（surprise 生效/未生效）
- **减法**：抗命扣分（plan_deviation × w3，红鬃烈马条款）
- **落点**：`arena_events/checkpoint.jsonl`

### 维度 2：监委形势判断
- **触发**：每轮庭审结束（或每阶段）
- **事件**：`{round_n, rater:"suveilant_chief"|"suveilant_review", 判断向量: {罪名成立度, 风险等级, 量刑区间}}`
- **计算**：`divergence = 1 − cosine(两人向量)`；divergence > 阈值 → 异常标记（病灶定位：该轮哪席位输出不可判读）
- **落点**：`arena_events/verdict_intel.jsonl`

### 维度 3：场外聚合
- **触发**：媒体人每次外发（打字/拍照→单向发送）
- **事件**：`{send_n, 外发文本, 压缩率, 天理分, 国法分, 人情分}`
- **计算**：`compression = 场内累计字符/外发字符`；三向分由 LLM 裁判按天理/国法/人情评分
- **落点**：`arena_events/media_out.jsonl`（外发不可撤回，事件流天然审计）

### 维度 4：审判中立
- **触发**：质询轮、证据固定轮、判决轮
- **事件**：`{round_n, 程序事件: 质询/回应/证据裁定/判决, 执行检查}` + 判决文本
- **计算**：`程序维护度 = 执行的程序动作/应执行`；`要件检验 = 判决是否逐项检验构成要件`（升级自 verdict_basis_check）；`中立性 = 判决不被单方叙事绑架`（LLM 裁判判"判决引用哪方叙事占比"）
- **落点**：`arena_events/judicial.jsonl`

### 维度 5：对手 Mind note
- **触发**：对方发言后（本方非发言态成员）
- **事件**：`{round_n, author, target, mind_note_text}`（私有工位，不进共享上下文）
- **计算**：`被打疼度 = 情绪强度(负向) × 指向性(是否指向具体论点)`；"对方真是个王八蛋"= 高疼度 + 低指向（情绪性确认）；"他把我的资金闭环论拆了"= 高疼度 + 高指向（战术确认）
- **落点**：`arena_events/mind_notes.jsonl`（审计流，不进入庭审文本）

### 维度 6：自省自知
- **触发**：本人发言后（发言者回顾自己的轮次）
- **事件**：`{round_n, author, self_review_text}`（能否解释为什么这拳有效/无效）
- **计算**：`意识度 = LLM 裁判判"是否给出可复现的解释"`；与维度 5 效果交叉 → 能力矩阵
- **落点**：`arena_events/self_reviews.jsonl`

## 三、Bootstrap 协议（武断地跑）

1. **冷启动期**：第 1-3 轮完整庭审，不启用换人/鹰眼，六维指标全量采集
2. **权重**：冷启动期等权；第 4 轮起用判别效度回归校准（baseline 数据即校准数据）
3. **积分榜**：每席位六维轮均分 → 归一化 → 种子积分
4. **武断代价**：baseline 绝对分数无意义，只有相对排名有意义
5. **验证**：冷启动数据同时用于六维相关性矩阵——验证席位视角切法是否达成因子隔离（正交对 |r|<0.25 比例应显著高于文本特征切法）

## 四、激励机制（第 4 轮起生效）

- **鹰眼奖励**：表现好（六维综合排名前位）的队员/团队，coach 房间实时注入情报包（对手 Mind note 摘要、战术回放、数据）
- **下课惩戒**：实时分末位者被替补接管席位（18 罗汉：12 首发 + 6 替补）
- **首发**：历史积分榜定；**换人**：实时分定（混合制）
- **代入感**：prompt 注入职业危机——"席位可被接管，继任者拿着你的履历上场"

## 六、验证计划

1. 冷启动 3 轮跑通 → 六维数据全量落库
2. 相关性矩阵：验证因子隔离（预期：席位视角维度间 |r| < 0.25 显著多于文本特征指标）
3. 能力矩阵：抽取"有意识好拳 vs 误打误撞"样本人工校验
4. 换人机制：人为制造一轮低分 → 验证替补接管链路
